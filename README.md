# Udhav's Village

A calm 3D village that runs my day: Today, School, Work and Gym, with a third-person walk mode.

Open it at **https://iphone-walls.github.io/village/**

- On iPad or iPhone: Share → Add to Home Screen. It opens full screen like an app and works offline.
- Everything you add is saved on that device only. Nothing is stored in this repository.
- Settings (•••) → Save a backup / Load a backup moves your data between devices.
- The AI team and live store revenue only work in the Claude version.
